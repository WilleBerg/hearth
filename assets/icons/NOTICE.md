# Icon sources

- `plex.svg`, `youtube.svg`, `twitch.svg`, `kodi.svg`, `steam.svg` — from
  [Simple Icons](https://simpleicons.org) (CC0 1.0 Universal), recolored for
  the dark theme.
- `tv4.svg`, `svt.svg` — a generic broadcast-icon placeholder from
  [Feather Icons](https://feathericons.com) (MIT), since neither channel has
  a brand icon in Simple Icons. Replace with real brand icons if/when
  available.
