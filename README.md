# Hearth

A self-hosted "smart TV" hub for a Raspberry Pi 5: a fullscreen, fully
config-driven home screen for launching Plex, YouTube, Kodi, and other
apps, without the ads, slowness, and limitations of a commercial smart TV.

See [`self_host_smart_tv.pdf`](./self_host_smart_tv.pdf) for the full design
doc.

**Status:** v1 prototype in progress.
